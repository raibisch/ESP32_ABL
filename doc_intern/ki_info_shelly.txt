Um die Rückmeldung des Shelly Plus 1 auszuwerten, müssen Sie nach dem Senden des Schaltbefehls den aktuellen Gerätestatus abfragen. Da die direkte Antwort {"was_on": false} nur den vorherigen Zustand verrät, liefert erst die anschließende Statusabfrage die Gewissheit, ob das Relais nun tatsächlich eingeschaltet ist.
Hier sind zwei gebrauchsfertige Skript-Beispiele.
## Option 1: Python-Skript (Für PC, Raspberry Pi oder Server)
Dieses Skript nutzt die integrierte Bibliothek urllib.request. Es schaltet den Shelly ein, fragt danach den echten Live-Status ab und gibt Erfolg oder Fehler aus. [1] 
Hier ist Ihr Skript.
import json
import urllib.request
import urllib.error
## Konfiguration: Ersetzen Sie dies mit der IP Ihres Shellys
SHELLY_IP = "192.168.xxx.xxx"
def schalte_und_pruefe_shelly():
url_schalten = f"http://{SHELLY_IP}/rpc/Switch.Set?id=0&on=true"
url_status = f"http://{SHELLY_IP}/rpc/Switch.GetStatus?id=0"
try:
# 1. Schaltbefehl senden
with urllib.request.urlopen(url_schalten, timeout=5) as response:
# Die Antwort des Schaltbefehls (z.B. {"was_on": false})
daten_schalten = json.loads(response.read().decode())
print(f"[Info] Schaltbefehl gesendet. Vorheriger Zustand (was_on): {daten_schalten.get('was_on')}")
# 2. Live-Status zur Verifikation abfragen
with urllib.request.urlopen(url_status, timeout=5) as response:
daten_status = json.loads(response.read().decode())
ist_eingeschaltet = daten_status.get("output")
# 3. Auswertung des echten Zustands
if ist_eingeschaltet is True:
print("✅ Erfolg: Das Relais des Shelly ist jetzt EINGESCHALTET.")
return True
else:
print("❌ Fehler: Der Befehl wurde gesendet, aber das Relais ist AUSGESCHALTET.")
return False
except urllib.error.URLError as e:
print(f"❌ Netzwerkfehler: Shelly unter {SHELLY_IP} nicht erreichbar. ({e.reason})")
return False
except Exception as e:
print(f"❌ Unbekannter Fehler: {e}")
return False
## Skript ausführen
if name == "main":
schalte_und_pruefe_shelly()
## Option 2: Bash/Shell-Skript (Für Linux, macOS oder Home Assistant)
Wenn Sie den Befehl direkt im Terminal oder in einem Cronjob nutzen möchten, kombiniert dieses Skript curl und das JSON-Werkzeug jq.
Hier ist Ihr Skript.
#!/bin/bash
## Konfiguration: Ersetzen Sie dies mit der IP Ihres Shellys
SHELLY_IP="192.168.xxx.xxx"
## 1. Schaltbefehl senden (Ausgabe wird unterdrückt)
curl -s "http://${SHELLY_IP}/rpc/Switch.Set?id=0&on=true" > /dev/null
## Eine kurze Pause von 200ms einlegen, damit das Relais Zeit zum Schalten hat
sleep 0.2
## 2. Live-Status abfragen und den Wert von "output" auslesen
LIVE_STATUS=(curl -s "http://{SHELLY_IP}/rpc/Switch.GetStatus?id=0" | jq '.output')
## 3. Auswertung
if [ "$LIVE_STATUS" = "true" ]; then
echo "✅ Erfolg: Das Relais des Shelly ist jetzt EINGESCHALTET."
exit 0
else
echo "❌ Fehler: Relais ist AUSGESCHALTET oder Shelly nicht erreichbar."
exit 1
fi
## Funktionsweise der Auswertung

   1. Zwei-Schritt-Verfahren: Beide Skripte senden zuerst den Befehl Switch.Set und rufen danach sofort Switch.GetStatus auf.
   2. Daten-Validierung: Das Skript sucht im JSON-Ergebnis der Statusabfrage nach dem Schlüssel "output". Nur wenn dieser explizit den Boolean-Wert true besitzt, gilt der Schaltvorgang als erfolgreich verifiziert.

Das Dimmen einer Wallbox nach § 14a EnWG (Drosselung auf maximal 4,2 kW bei drohender Netzüberlastung) lässt sich mithilfe eines Shelly-Relais technisch zuverlässig umsetzen. [1, 2] 
Da der Netzbetreiber das Signal über ein physisches Gerät (Steuerbox des Smart Meter Gateways oder Rundsteuerempfänger) ausgibt, dient der Shelly hier als Brücke/Übersetzer über das WLAN oder LAN. [1, 3, 4, 5] 
Hier sind die zwei gängigsten Wege, wie Sie das einrichten können.
------------------------------
## Methode 1: Direkt über den digitalen Steuereingang (Empfohlen)
Viele moderne Wallboxen (z. B. von cFos, go-e oder Tesla) besitzen einen sogenannten Downgrade-Eingang oder einen potentialfreien Kontakt für die EVU-Sperre. [1, 6, 7] 

   1. Hardware koppeln: Schließen Sie den potentialfreien Ausgang eines [Shelly Pro 1](https://shelly-forum.com/thread/31518-shelly-mit-rundsteuerempfaenger-verbinden/) oder Shelly Plus 1 an den Steuereingang der Wallbox an. [8] 
   2. Signal vom Netzbetreiber: Der Schaltausgang des Rundsteuerempfängers/der Steuerbox des Netzbetreibers wird auf den Eingang (SW) des Shellys gelegt. [9] 
   3. Logik in der Wallbox: In den Einstellungen der Wallbox-Software konfigurieren Sie den Kontakt so, dass bei geschlossenem (oder geöffnetem) Kreis die Ladeleistung auf 6A dreiphasig (~4,2 kW) gedrosselt wird. Der Shelly reicht das Signal einfach eins zu eins weiter. [10, 11, 12] 

## Methode 2: IP-basiertes Dimmen (Smart Home / Software)
Falls die Steuerbox des Netzbetreibers im Zählerschrank sitzt, die Wallbox aber weit entfernt in der Garage hängt und kein Steuerkabel liegt, nutzen Sie zwei Shellys (oder ein Smart-Home-System) als Funkstrecke. [4] 

   1. Sender im Zählerschrank: Ein Shelly Pro 1 (Hutschiene) erfasst am Eingang (SW) das Schaltsignal des Netzbetreibers. [8, 9] 
   2. Übertragung: Löst der Netzbetreiber aus, sendet dieser Shelly per HTTP-Webhook (DDD-Rules) oder über ein übergeordnetes System (wie Home Assistant, ioBroker oder evcc) einen Befehl an die Wallbox. [10, 13] 
   3. Befehl ausführen: Die Wallbox empfängt den API-Befehl über das lokale Netzwerk und regelt den Ladestrom softwareseitig auf 4,2 kW herunter. [1, 5]

Hier ist der genaue Ablauf und die technische Umsetzung für Ihr Szenario:
## Der technische Aufbau

   1. Shelly 1 (Sender im Zählerschrank):
   * Anschluss: Der potentialfreie Kontakt der Steuerbox (Netzbetreiber) wird an den SW-Eingang dieses Shellys angeschlossen.
      * Einstellung: In den Shelly-Einstellungen stellen Sie den Button-Type auf "Detached" (Getrennt). Dadurch schaltet das Relais im Shelly nicht selbst, sondern registriert nur den Zustand des Kontakts. [1, 2] 
   2. Shelly 2 (Empfänger an der Wallbox):
   * Anschluss: Der potentialfreie Ausgang (I/O) dieses Shellys wird mit dem Steuereingang (Downgrade/EVU-Sperre) der Wallbox verbunden.
   
------------------------------
## Die Konfiguration per Web-API (HTTP-Webhooks)
Sie benötigen dafür keine Smart-Home-Zentrale (wie Home Assistant). Die Shellys kommunizieren direkt miteinander über lokale HTTP-Befehle (DDD-Rules).
Sie richten im Sender-Shelly (Zählerschrank) zwei Webhooks ein, die bei einer Statusänderung am SW-Eingang ausgelöst werden:
## Befehl für "Drosselung EIN" (Kontakt schließt)

* Event: Input oder Switch ON
* URL: http://[IP_VON_SHELLY_2]/rpc/Switch.Set?id=0&on=true
* (Hinweis: Bei älteren Shelly Gen 1 Modellen lautet die URL: http://[IP_VON_SHELLY_2]/relay/0?turn=on)

## Befehl für "Drosselung AUS / Normalbetrieb" (Kontakt öffnet)

* Event: Input oder Switch OFF
* URL: http://[IP_VON_SHELLY_2]/rpc/Switch.Set?id=0&on=false
* (Hinweis: Bei älteren Shelly Gen 1 Modellen lautet die URL: http://[IP_VON_SHELLY_2]/relay/0?turn=off)

## ⚠️ Wichtige Praxis-Tipps für diesen Aufbau

* Feste IP-Adressen: Vergeben Sie unbedingt in Ihrem WLAN-Router feste IP-Adressen für beide Shellys. Ändert sich die IP des Empfängers, läuft der Webhook ins Leere und die Wallbox dimmt im Ernstfall nicht.
* Das "Fail-Safe"-Problem (WLAN-Ausfall): Das ist der einzige rechtliche Graubereich bei dieser Methode. Fällt Ihr WLAN aus, erfährt der Empfänger-Shelly nichts vom Drosselbefehl. Streng genommen fordert der Netzbetreiber eine ausfallsichere Steuerung.
* Die Lösung für maximale Sicherheit: Nutzen Sie die Shelly Pro-Serie (z. B. Shelly Pro 1). Diese Geräte haben einen LAN-Anschluss. Wenn Sie beide Shellys per Netzwerkkabel in Ihr Heimnetz einbinden, ist die Verbindung absolut stabil und unempfindlich gegenüber WLAN-Störungen.

## 1. Welche Shellys kommen infrage?
Sie benötigen für beide Seiten Shellys mit potentialfreien Kontakten (Trockenkontakte), damit keine Fremdspannung auf die Geräte des Netzbetreibers oder der Wallbox übertragen wird. [1] 

* Für den Zählerschrank (Sender):
* [Shelly Pro 1](https://shelly-forum.com/thread/31518-shelly-mit-rundsteuerempfaenger-verbinden/) (Empfohlen, da Hutschienenmontage und LAN-Anschluss für maximale Stabilität).
   * Alternative: Shelly Plus 1 (Günstiger, kompakt für Unterputzdosen, nur WLAN).
* Für die Wallbox (Empfänger):
* Shelly Plus 1 (Perfekt zum Einbau direkt im Gehäuse oder der Unterputzdose neben der Wallbox). [2] 

------------------------------
## 2. Klemmenbezeichnung & Schaltplan
Beide Shellys müssen dauerhaft mit Strom versorgt werden (230V AC). [3] 
## Shelly 1: Der Sender im Zählerschrank (z. B. Shelly Pro 1 oder Plus 1) [4] 

* L / N: Spannungsversorgung für den Shelly selbst (230V Phase und Neutralleiter). [5, 6] 
* SW (Switch-Eingang): Hier wird der erste Draht vom potentialfreien Kontakt der Steuerbox (Netzbetreiber) angeschlossen.
* L (als Brücke zum Schalter): Der zweite Draht von der Steuerbox des Netzbetreibers wird auf Phase (L) gelegt.
* Funktionsweise: Schließt der Netzbetreiber den Kontakt, fließen 230V in den SW-Eingang. Der Shelly registriert das Signal (Einstellung: Detached Mode), schaltet aber sein eigenes Relais nicht.

## Shelly 2: Der Empfänger an der Wallbox (z. B. Shelly Plus 1) [7] 

* L / N: Spannungsversorgung für den Shelly selbst (230V Phase und Neutralleiter). [8, 9] 
* I (Input) & O (Output): Dies ist der potentialfreie Relais-Ausgang.
* Verbinden Sie I und O direkt mit den beiden Kontakten des Drossel-Eingangs (EVU-Sperre) Ihrer Wallbox. (Reihenfolge ist egal).

## 3. Das Fail-Safe-Konzept (Ausfallsicherheit bei WLAN-Verlust)
Da der Drosselbefehl über das Netzwerk gesendet wird, verlangt das Gesetz (§ 14a EnWG) im Grunde ein System, das bei einem Verbindungsabbruch automatisch in den sicheren Zustand (gedimmt oder abgeschaltet) geht.
Das lässt sich über ein Skript auf dem Empfänger-Shelly (Shelly 2) und einen zyklischen Ping (Heartbeat) lösen:

   1. Der "Drossel-Logik"-Wechsel: Konfigurieren Sie den Eingang der Wallbox so, dass sie gedrosselt wird, wenn der Kontakt geöffnet ist (Ruhestromprinzip). Im Normalbetrieb ist das Relais des Empfänger-Shellys also dauerhaft geschlossen.
   2. Der Heartbeat: Der Sender-Shelly schickt nicht nur bei Statusänderung ein Signal, sondern über einen Timer alle 60 Sekunden einen "Mir geht es gut"-Befehl an den Empfänger-Shelly.
   3. Das Fail-Safe-Skript: Auf dem Empfänger-Shelly läuft ein einfaches, kurzes JavaScript (unter "Scripts" in der Shelly-Oberfläche). Dieses Skript startet einen 90-Sekunden-Timer. Jedes Mal, wenn der Heartbeat vom Sender ankommt, wird der Timer zurückgesetzt.
   4. Der Ernstfall: Fällt das WLAN aus, bleibt der Heartbeat aus. Der Timer läuft nach 90 Sekunden ab, das Skript öffnet das Relais automatisch und die Wallbox regelt sicherheitshalber auf 4,2 kW ab, bis das WLAN wieder da ist.

Hier sind beide Schritte Schritt für Schritt erklärt: zuerst die Einrichtung des Detached Mode (wichtig, damit nichts funkt, wo es nicht soll) und danach das fertige Skript für die Ausfallsicherheit.
------------------------------
## Teil 1: "Detached Mode" beim Sender-Shelly einrichten
Damit der Sender-Shelly das Signal vom Netzbetreiber nur registriert, aber nicht sein eigenes Relais schaltet, müssen Sie den Schalter vom Relais entkoppeln.

   1. Öffnen Sie die Web-Oberfläche oder die App des Sender-Shellys.
   2. Gehen Sie auf Settings (Einstellungen) ➡️ Input/Output (Eingang/Ausgang).
   3. Wählen Sie den entsprechenden Kanal (meistens Switch 0).
   4. Suchen Sie nach Input Mode (Eingangsmodus) und stellen Sie diesen auf Switch (Schalter).
   5. Suchen Sie nach Relay Mode (Relaismodus) oder Button Type und wählen Sie Detached (Getrennt).

Jetzt sieht der Shelly, wenn der Netzbetreiber schaltet, reagiert aber nur noch über die von Ihnen eingerichteten Webhooks (URLs).
------------------------------
## Teil 2: Das Fail-Safe-Skript (für den Empfänger-Shelly)
Dieses Skript sorgt dafür, dass die Wallbox bei einem WLAN-Ausfall automatisch in den sicheren, gedrosselten Zustand geht.
## Die Logik dahinter:

* Normalbetrieb (Auto darf schnell laden): Das Relais am Empfänger-Shelly ist AN (Kontakt geschlossen). Die Wallbox weiß: Alles im grünen Bereich.
* Gedrosselt (Netzüberlastung ODER WLAN-Ausfall): Das Relais ist AUS (Kontakt offen). Die Wallbox regelt auf 4,2 kW ab.

## Schritt 1: Skript auf dem Empfänger-Shelly (Wallbox) aktivieren

   1. Gehen Sie auf die Web-Oberfläche des Empfänger-Shellys.
   2. Klicken Sie im linken Menü auf Scripts und dann auf Create Script (Skript erstellen).
   3. Kopieren Sie den folgenden Code eins zu eins hinein:

// Fail-Safe Skript für §14a EnWG Drosselung// Läuft auf dem EMPFÄNGER-Shelly an der Wallbox
let watchdogTimer = null;const TIMEOUT_MS = 90000; // 90 Sekunden ohne Signal = WLAN-Ausfall vermutet
// Funktion: Schaltet das Relais AUS (Sicherer Zustand = Wallbox gedrosselt)function setSafeState() {
  print("FAIL-SAFE ausgelöst: Kein Heartbeat empfangen. Wallbox wird gedrosselt!");
  Shelly.call("Switch.Set", { id: 0, on: false });
}
// Funktion: Wird aufgerufen, wenn der Sender-Shelly sich meldetfunction resetWatchdog() {
  // Falls der Timer läuft, löschen
  if (watchdogTimer) {
    Timer.clear(watchdogTimer);
  }
  // Neuen Timer starten
  watchdogTimer = Timer.set(TIMEOUT_MS, false, function() {
    setSafeState();
  });
}
// Lauscht auf eingehende HTTP-Befehle (Heartbeats)
Shelly.addEventHandler(function(event) {
  // Wenn das Relais vom Sender geschaltet wird oder ein Webhook reinkommt
  if (event.component === "switch:0") {
     resetWatchdog();
  }
});
// Beim Start des Shellys den Timer einmalig aktivieren
resetWatchdog();


   1. Klicken Sie auf Save (Speichern) und schalten Sie den Schalter bei dem Skript auf Enabled/Run (Aktiviert).

------------------------------
## Schritt 2: Die Webhooks beim Sender-Shelly (Zählerschrank) eintragen
Damit der Empfänger-Shelly weiß, dass das WLAN noch da ist, muss der Sender-Shelly regelmäßig ein Signal senden. Richten Sie dazu im Sender-Shelly unter Actions (Webhooks) zwei Befehle ein:

   1. Aktion bei Netzbetreiber-Drosselung (Kontakt schließt / Switch ON):
   * URL: http://[IP_DES_EMPFÄNGERS]/rpc/Switch.Set?id=0&on=false
      * (Erklärung: Schaltet das Empfänger-Relais aus ➡️ Wallbox dimmt).
   2. Aktion bei Normalbetrieb (Kontakt öffnet / Switch OFF):
   * URL: http://[IP_DES_EMPFÄNGERS]/rpc/Switch.Set?id=0&on=true
      * (Erklärung: Schaltet das Empfänger-Relais ein ➡️ Wallbox darf voll laden).
   3. Zusatz (WICHTIG für den Heartbeat):
   Damit der Timer im Empfänger nicht abläuft, wenn stundenlang keine Änderung vom Netzbetreiber kommt, erstellen Sie im Sender-Shelly unter Schedules (Zeitpläne) eine Aufgabe:
   * Intervall: Alle 1 Minute (oder CRON: * * * * *)
      * Befehl (wenn Netzbetreiber OFF ist): http://[IP_DES_EMPFÄNGERS]/rpc/Switch.Set?id=0&on=true
      * (Das sendet jede Minute das "Alles Okay"-Signal an das Skript).
